# TENFOLDIndustries

Preview of the Tenfold Industries website 2.0.

Live site (after Pages is enabled): https://xiexiejingyi.github.io/TENFOLDIndustries/

This repository publishes the static site from `main`. To turn on GitHub Pages:

1. Open [Settings → Pages](https://github.com/xiexiejingyi/TENFOLDIndustries/settings/pages)
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**
3. Set **Branch** to `main` and the folder to `/ (root)`
4. Click **Save**

The homepage, Projects, Inspiration, and Contact pages should go live within a minute.
